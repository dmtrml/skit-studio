# Скетч-студия

Плагин для Claude Code и Codex. Делает **вертикальный скетч 1080×1920, 35–45 секунд**: ночная комната, человек за столом с ноутбуком и его ИИ-помощник Ко (зелёный блок с лицом на экране). Сухая, вежливая, буквальная шутка про жизнь с ИИ. Картинка — настоящий 3D со светом, тенью, пылинками и глубиной резкости, персонаж жестикулирует, двигает головой и меняет выражение лица. Голос — Gemini TTS, два голоса в одном дубле.

## Пример

Готовый скетч, который делает плагин: `examples/ko-skit-example.mp4` (вертикальный, около 40 секунд).

## Что вы получаете

- сценарий-таблицу с 2–3 вариантами шутки на вашу тему;
- озвучку, паузы подобраны под комедию (пауза перед финальной репликой — до 1,2 с);
- **черновик ритма** в настоящем виде — вы судите только паузы и склейки;
- полный черновик: жесты, лица, реквизит, вставки (экран чата, редактор); перед показом Claude сам проверяет кадры по списку (пятна света, фокус на лицах, руки не в теле);
- музыку по желанию (варианты на готовой картинке, без перерендера);
- финал в 4K, уменьшенный до 1080×1920, громкость около −14 LUFS.

Свой персонаж вместо парня: можно дать картинку, Claude соберёт похожего (стилизованно, узнаваемо по силуэту, цветам и деталям — не копия).

## Что поставить

Всё ставит команда `/skit-studio:setup` по одному вашему «да»:

- Python 3.10+, Node.js 18+, ffmpeg;
- пакеты Python: faster-whisper, numpy, pillow, soundfile, scipy;
- playwright (для проверки кадров), движок HyperFrames (качается сам при первом запуске);
- ключ **Gemini API** — бесплатный, aistudio.google.com/apikey (входите аккаунтом Google). Командная строка не нужна: при установке откроется Блокнот с файлом, в него вставляете ключ и сохраняете; в чат ключ не присылайте. Бесплатный лимит — 10 озвучек в день на модель, нам нужна одна на скетч.

Видеокарта желательна, но не обязательна: без неё рендер идёт на процессоре, медленнее. Слабый компьютер, который перезагружается под нагрузкой, — включите `SKIT_THROTTLE=1` (очередь и разнесённый старт тяжёлых задач).

## Как начать

После установки напишите одну строку: **`/skit-studio:start`** (или просто «хочу скетч», «сделай скетч», «сними ролик с Ко»). Claude сам проверит установку, покажет пример и задаст три вопроса: шутка, герой, помощник.

1. Установите плагин: `/plugin marketplace add dmtrml/skit-studio`, затем `/plugin install skit-studio@skit-studio`.
2. `/skit-studio:setup` — установка и проверка.
3. `/skit-studio:start` — ведёт по всему пути. `/skit-studio:check` — проверка кадров готового черновика по списку.

## В Codex

Плагин работает и в Codex (проверено 18.11.2026: тот же скетч собран за 52 минуты).

1. `codex plugin marketplace add dmtrml/skit-studio`, затем `codex plugin add skit-studio@skit-studio`.
2. Напишите в Codex «хочу скетч» — дальше так же, вопросы придут списком вместо кнопок.
3. На Windows нужен Git Bash (`winget install Git.Git`): проверка установки покажет его строкой `bash`.
4. Озвучку и музыку Codex не слышит — послушайте черновик ритма сами.

## 4 решения, которые принимаете вы

1. **Шутка** — Claude предлагает 2–3, вы выбираете.
2. **Ритм** — смотрите черновик ритма: «ритм хороший» или какие паузы поменять.
3. **Картинка** — принимаете полный черновик или даёте правки.
4. **Музыка** — нужна ли, и (если качаем трек) разрешение на скачивание; выбираете вариант.

## Сколько это стоит

- Время: первый скетч ≈ 4 часа (из них около часа ваше ожидание рендеров). Второй, по готовому пути, — быстрее.
- Деньги: Gemini — бесплатный ключ; Claude — обычная подписка (скетч — это несколько миллионов токенов, большая часть уходит на помощников-исполнителей, а не на основную модель).
- Место: около 2 ГБ (модель Whisper, Chromium, HyperFrames) плюс сам скетч.
