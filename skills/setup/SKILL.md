# Установка Скетч-студии

Человек может не быть программистом. Говори по-русски, коротко; термин объясняй в скобках тремя словами. Каждую установку — только после его «да»; перед вопросом назови, что ставим, зачем (одна фраза), сколько места и минут.

`<plugin>` — папка плагина (`${CLAUDE_PLUGIN_ROOT}`; если пусто — две папки вверх от этого файла).

## 1. Что уже есть

Выполни `python "<plugin>/scripts/install.py"` (только проверка, ничего не ставит). Если `python` не отвечает или открывает Microsoft Store — Python не установлен: предложи поставить с python.org (отметить «Add to PATH»), после этого попроси перезапустить приложение (Claude или Codex).

Покажи вывод как есть. Строки `OK` не трогай.

## 2. Один вопрос со списком

Для каждой строки `НЕТ` — одна строка в вопросе (кнопки «Ставим всё» / «Выбрать»):

| Пункт | Зачем | Размер / время |
|---|---|---|
| node | движок рендера HyperFrames и инструменты проверки кадров | ≈ 80 МБ, 2 мин |
| ffmpeg | склейка звука и видео, громкость | ≈ 150 МБ, 2 мин |
| bash | Git Bash: запуск скриптов `.sh` (Windows; в Claude Code обычно уже есть) | `winget install Git.Git`, ≈ 300 МБ, 3 мин |
| pip | Whisper (разметка слов), числа, картинки, звук | ≈ 1 ГБ с моделью, 5 мин; модель Whisper large-v3 (≈ 3 ГБ) скачается при первой озвучке |
| playwright | снимки кадров для проверок (свет, фокус, руки) | ≈ 300 МБ (Chromium), 3 мин |
| hyperframes | прогрев движка | ≈ 100 МБ, 2 мин |

Что нужно сразу, а что нет: `playwright` нужен только для проверок кадров шага 9 (arm_sweep, focus_measure и др.) — черновик ритма и рендер работают без него; `hyperframes` прогревается сам при первом `check` (≈ 40 с). «НЕТ» у этих двух строк не блокирует шаги 1–8. Node, ffmpeg, pip и ключ Gemini нужны сразу.

Windows может спросить «Разрешить изменения?» — заранее скажи нажать «Да».

## 3. Установка

После «да»: `python "<plugin>/scripts/install.py" --install --only <список через запятую>` (без `--only` — всё недостающее). Скрипт печатает «готово» или «не вышло: …» на каждый пункт. После установки Node.js или ffmpeg новое окно может не видеть программу — попроси перезапустить приложение Claude и повтори проверку.

## 4. Ключ Gemini (голос)

Строка `gemini` = НЕТ: скажи человеку, что ключ бесплатный и голос без него не сделать. Шаги для него: открыть aistudio.google.com/apikey, войти аккаунтом Google, нажать «Create API key», скопировать. Дальше:

- Запусти `python "<plugin>/scripts/install.py" --key-file`: он создаёт `~/.skit-studio/gemini-key.txt` и открывает его в Блокноте (macOS — TextEdit). Скажи человеку: «Открылось окно Блокнота. Вставьте ключ на пустую строку, нажмите Ctrl+S и закройте окно. В чат ключ не присылайте». Командная строка человеку не нужна, перезапуск приложения тоже. Сам этот файл не читай и не показывай.
- Когда человек ответит, что сохранил, — запусти `install.py` ещё раз: строка `gemini` должна стать OK.
- Кто умеет — может вместо файла задать переменную среды `GEMINI_API_KEY` (Windows: `setx GEMINI_API_KEY "<ключ>"` в PowerShell и перезапуск приложения; macOS/Linux: `export` в профиле оболочки). Переменная главнее файла.

Ключ никогда не печатай, не записывай в файлы скетча, не отправляй никуда, кроме `generativelanguage.googleapis.com`. Проверить, что он виден: `install.py` пишет «ключ найден» (значение не показывает). Бесплатный лимит: 10 озвучек в день на модель — одной на скетч хватает.

## 5. Слабый компьютер

Если ПК перезагружался или зависал под рендером: включи очередь тяжёлых задач — переменная среды `SKIT_THROTTLE=1` (не больше двух задач сразу, старт с паузой 20 с, рендер в 2 потока). Без видеокарты NVIDIA рендер идёт на процессоре — медленнее, но работает.

## 6. Итог

Снова `python "<plugin>/scripts/install.py"`. `ГОТОВО` — скажи одной фразой и предложи `/skit-studio:start`. Иначе назови человеку один оставшийся шаг.
